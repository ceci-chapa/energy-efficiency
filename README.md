# Energy Efficiency 

### Assessing Multiple Linear Regression Models of Heating and Cooling Loads Using Ecotect Building Features


The Energy Efficiency dataset contains a collection of building shapes that were simulated in a software known as Ecotect. To predict two different responses (heating load and cooling load), several settings were simulated to collect 768 building shapes using 8 predictors—relative compactness, surface area, wall area, roof area, overall height, orientation, glazing area, and glazing area distribution.

Dataset link can be found here: [Energy Efficiency Dataset](https://archive.ics.uci.edu/dataset/242/energy+efficiency "Energy Efficiency Dataset")
